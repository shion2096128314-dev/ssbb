# 平台规则与选题定位：起点 / 番茄写家族修仙·系统文

> 本文分三类内容，写作时严禁混为一谈：
> - **【机制】**：免费阅读与付费订阅两种模式的底层逻辑，相对稳定，可以直接当规律讲。
> - **【经验值】**：同行做法与常见写法，会随平台调整变化，只能当参考，不能说成硬规则。
> - **【需联网核实】**：签约门槛、全勤奖、榜单口径、分成比例、审核红线、当前热门题材——这类内容**必须联网查证后再讲，并说明出处与时间**，不许凭记忆当事实。

---

## 一、两条路线的底层差别

| 维度 | 起点（付费订阅为主） | 番茄（免费阅读 + 广告分成） |
|---|---|---|
| 读者成本 | 要花钱，会忍一段 | 免费，划走零成本 |
| 变现来源 | 章节订阅、月票打赏、IP 改编 | 广告曝光、阅读时长、IP 改编 |
| 核心指标 | 均订、追订、收藏、月票 | 完读率、追读、留存、在读人数 |
| 开篇容忍度 | 前 3 章可略铺，但第 1 章仍必须有钩子 | 前 200 字没冲突就流失 |
| 单章长度 | 2000–3000 字常见，允许 3000+ | 主流 1500–2500 字，2000 上下最稳 |
| 段落长度 | 可略长，仍建议短段 | 必须短，一段不超过 3 行（手机屏） |
| 慢热空间 | 有一点，但代价是收藏掉 | 几乎没有 |
| 章节钩子 | 重要，但章节结尾可以收束一小段 | 极其重要，章末钩子是留存命脉 |
| 断更影响 | 掉订阅与推荐位 | 直接掉推荐权重，比起点更敏感 |
| 家族文卖点 | 「家族流」「宗门世家」标签自带付费读者盘 | 需要靠书名简介半秒讲清爽点 |

**共同结论（两条线都成立）**：前 3 章定生死；主角不能长期憋屈；章末必须有钩子；不给读者摆设定。

---

## 二、家族修仙 / 系统文在两条线上的写法差异

| 写作项目 | 起点写法 | 番茄写法 |
|---|---|---|
| 第 1 章交代多少族谱 | 可以出现 2–3 个族人 + 家族处境，但不得列名单 | 只出现「主角 + 一个压迫者 + 一个信息人物」，族谱往后放 |
| 境界体系何时讲 | 第 1–3 章自然带出主角境界与全族最高战力 | 只交代主角最弱、对方更强，具体境界名第 3 章后再统一 |
| 憋屈章节能拖多久 | 最多 1 章，第 2 章必须还手 | 不超过半章，本章受气本章还 |
| 爽点密度 | 每章 1 个小爽点，3–5 章一个中爽点 | 每章 1–2 个爽点，2–3 章一个中爽点 |
| 卷长与卷末 | 一卷 25–40 万字，卷末大高潮 | 一卷 15–30 万字，卷末大爆点 + 强钩子 |
| 家族成长写法 | 可以写制度与资源账，读者爱吃设定 | 只写结果：族田多了几亩、族库多了多少灵石，一两句带过 |
| 系统面板 | 可以贴完整面板，读者会研究数值 | 面板一次只贴 3–5 行，且必须出现在冲突里 |
| 主角姓名与称呼 | 可略雅，但要好记 | 必须好记好读，忌生僻字与同音混 |

## 三、核心机制【机制】

1. **免费平台的读者是「刷」到你的书的**。书名 + 简介 + 封面决定点击率，点击率低则再好的内容也进不了更大的流量池。家族修仙文的书名要把「家族 + 金手指 + 结果」三件事塞进半秒能读完的一句话里。
2. **留存大于单章精彩**。平台按留存与完读率决定给不给推荐，所以章末钩子的价值高于本章高潮。
3. **追读看钩子，留存看中爽点**。每 3–5 章必须给一个中爽点（族比赢一场、族库钥匙到手、打脸一个房头），否则读者会在「过渡章」处流失。
4. **付费平台的读者会为「确定性」付费**。他们买的是「下一章一定更爽」，所以可以略微压节奏，但不能压爽点。
5. **两平台都吃「血缘共同体」这一口**：家族修仙的独门爽点是「我的强会变成全族的强」，这是散修流给不了的。写作时要反复让读者看见这条正反馈。

## 四、家族修仙选题与定位表【经验值】

| 选题方向 | 一句话卖点 | 适合平台 | 金手指类型 | 风险 |
|---|---|---|---|---|
| 族运面板流 | 我能看见全族的族运，也能改 | 两条都行 | 族运可视 + 加点 | 面板刷屏 |
| 祖灵传承流 | 祖祠里的老祖宗，只跟我说话 | 起点更佳 | 祖灵指点 + 传承 | 老爷爷抢戏 |
| 贡献点兑换流 | 家族的贡献点，在我这儿能翻倍 | 番茄更佳 | 兑换/商城 | 数值通胀 |
| 破绽修补流 | 全族功法都有破绽，只有我知道 | 两条都行 | 看见缺陷 + 补全 | 万能化 |
| 血脉提纯流 | 我改良了家族血脉，全族跟着变强 | 起点更佳 | 血脉优化 + 遗传 | 前期弱 |
| 种田暴兵流 | 灵田一年三熟，族里人越生越多 | 番茄更佳 | 资源爆发 | 缺冲突 |
| 族谱留名流 | 族谱上我的名字，越写越靠前 | 两条都行 | 声望/排名系统 | 爽点抽象 |

**选题自检三问**：主角凭什么赢（一句话）？家族因他发生什么可见变化（一句话）？三卷后对手是谁（一句话）？三句都答不上，就不要开书。

## 五、标签、分类与简介（运营层）【需联网核实】

- 分类与标签直接影响推荐池归类，**不同平台、不同时期的标签名在变**，发布前必须去作家后台或官方公告核对当前可选标签。
- 简介写法：前两句给处境，第三句给金手指，第四句给夸张结果，最后一句留钩子。**不要写世界观介绍，不要写作者自述。**
- 书名不要文艺、不要双关、不要生僻字。
- 以下内容**必须联网核实后再引用**：签约条件、全勤/保底规则、分成比例、榜单与入榜门槛、新书期定义、审核红线与禁写题材、当前热门题材数据、封面规格。
- 核实后的表述格式：「按 X 年 X 月 官方/后台 口径，……；同行经验是……」，绝不把两者混成一句。

## 六、内容红线（写作层面，恒定不变）

1. 不抄任何已有小说的原文、独创桥段与人设组合。
2. 不写违法违规、涉政涉黄涉暴、教唆犯罪、真实人物造谣类内容。
3. 不承诺签约、上架、收益、榜单成绩。
4. 不因催更而注水、重复交代设定、拖长过渡章。
5. 涉及时效性平台规则时，只讲能核实的部分，不确定就说不确定。

---

## 七、更新节奏建议【经验值，以后台与官方公告为准】

| 项目 | 建议 |
|---|---|
| 单章字数 | 番茄 1500–2500（主流 2000）；起点 2000–3000 |
| 日更量 | 新人保 4000 字；起量期 6000–8000 字 |
| 更新时段 | 固定时段更新，便于读者养成追读习惯；一天内别拆太散 |
| 断更 | 两平台都不许断；宁可少更不断更 |
| 存稿 | 开书前至少存 10 章（2 万字）再开始发 |
| 新书期 | 新书期窗口内要稳更、要冲完读率与追读（具体窗口定义需联网核实） |
| 卷末 | 每卷最后 3 章必须连续给大爽点 + 强钩子 |

## 八、书名与简介公式（可直接套）

### 8.1 书名四个公式

| 公式 | 结构 | 说明 | 示例（原创） |
|---|---|---|---|
| 身份反差式 | 低位身份 + 夸张动作 | 家族文最稳，一眼看出主角被打压 | 《族里最废的三房，把族谱改成了天书》 |
| 分类词前置式 | 题材词 + 金手指 | 方便平台归类，点击率稳 | 《家族修仙：我有一座族运面板》 |
| 挑衅式 | 否定句 + 我 | 情绪拉满，适合短视频切片传播 | 《你们守的是祖训，我改的是族运》 |
| 信息差式 | 全网/全族都不知道 + 只有我 | 把后期爽点前置 | 《全族的功法都有缺，只有我看得见》 |

**书名自检**：念一遍，半秒内能不能说出「谁、靠什么、能得到什么爽」？说不出就重起。禁文艺、禁双关、禁生僻字、禁超过 12 字（番茄尤其）。

### 8.2 简介五句结构

```
① 处境（一句，带具体数值或期限）：陈砚在族里排末位，月俸三枚下品灵石，还要供弟弟开脉。
② 转折（一句，带事件）：族祭那天，祖祠的旧匾在他眼里裂开了一道缝。
③ 金手指（一句，说清怎么用）：他能看见族运的流向——哪一房在吸全族的运，哪一族快断了根。
④ 夸张结果（一句，具体可见）：他用三炷香改了族谱上一行字，三房的灵田当年多收了两成。
⑤ 钩子（一句，指向更大危机）：可族运流向的尽头，站着的是自家老祖。
```

**简介禁止**：写世界观设定、写作者自述、写「本书将讲述」、写超过 200 字、把爆点全剧透完。

### 8.3 书名候选交付格式

出 5 个，风格错开（四个公式各至少 1 个），每个附一句话卖点，最后推荐 1 个并说明理由。不要交 5 个同款书名。

## 九、家族文的四种开书姿势

| 姿势 | 第 1 章在做什么 | 适合平台 | 风险 |
|---|---|---|---|
| 受辱逆袭开局 | 主角被同族羞辱，金手指当场兑现 | 番茄 | 开局俗，必须靠细节与对话区分度取胜 |
| 族难开局 | 族里出事（被夺灵田/族老重伤/族战将起），主角被推出去 | 两条都行 | 人物多，需严格控制出场 |
| 家传秘密开局 | 主角继承一件祖物，牵出家族旧案 | 起点 | 前期爽点慢，必须第 2 章就兑现一次 |
| 反向开局 | 主角是全族的希望，但族里没人信（重生/预知向） | 两条都行 | 容易写成旁白解释，要靠冲突演出来 |

**四条铁律**：无论哪种姿势，第 1 章都必须有 ①一个具体的欺压或危机 ②金手指兑现一次 ③一个期限或倒计时 ④一个章末钩子。

## 十、选题期的三类废案（判断要不要开书）

| 废案类型 | 表现 | 为什么不行 | 救活方式 |
|---|---|---|---|
| 只有设定没有对手 | 能讲清族谱与体系，讲不出三卷后打谁 | 读者没有期待 | 先把反派阶梯（见 `07`）列出来再回来看设定 |
| 只有金手指没有家族 | 家族只是背景板，故事换成散修也成立 | 家族文的独门爽点丢了 | 让金手指必须通过家族才能生效（族运/祖祠/贡献点） |
| 只有爽点没有成长刻度 | 一直在打脸，家族一直是那个样子 | 读者感觉不到推进 | 用 `03` 的家族成长刻度表，给每卷定一个可见的台阶 |

## 十一、一页速查

```
两条线共同底线：
  第1章 第一句话有冲突 → 主角处境惨但不蠢 → 金手指亮相 → 小爽点 → 钩子
  每章   1个小爽点 + 1个章末钩子，缺一不可
  每3-5章 1个中爽点；每卷 1个大高潮
  主角   受气不过一章；不降智、不圣母、不优柔寡断

番茄加码：段短、章短、钩子强、族谱后置、面板少贴
起点加码：可略铺设定，但收藏掉得比番茄快，别赌慢热
```
