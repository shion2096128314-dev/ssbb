# 黄金三章（家族修仙·系统文专用）

> 通用爽文的三章骨架已在 `fanqie-shuangwen` 技能里讲过。本文只解决家族修仙与系统文特有的两个难题：**族谱人物太多、设定太厚，怎么在前三章不劝退**，以及**系统面板怎么贴才不掉留存**。

---

## 一、开篇三章的硬指标

| 指标 | 第 1 章 | 第 2 章 | 第 3 章 |
|---|---|---|---|
| 新出场有名字的人 | ≤ 3 个（主角、压迫者、信息人物） | ≤ 2 个新增 | ≤ 3 个新增 |
| 提到的家族成员总数 | ≤ 4 个 | ≤ 6 个 | ≤ 8 个 |
| 出现的新专有名词（境界/功法/地名/族规） | ≤ 5 个 | ≤ 5 个 | ≤ 5 个 |
| 必须交代的家族信息 | 家族现在的处境（穷/弱/被欺） | 家族里谁说了算、谁在整他 | 家族能给他什么、他给家族带来什么 |
| 爽点 | 1 个小爽点 | 1 个小打脸 | 1 个大爽点（当众） |
| 钩子 | 指向更大危机 | 指向更强的人 | 指向全书级秘密 |
| 篇幅 | 番茄 1800–2200；起点 2200–3000 | 同左 | 同左 |

**三章结束时，读者必须能一句话回答**：主角是谁、他在哪个家族、他凭什么赢、接下来要看什么。

---

## 二、第 1 章：只做四件事

**第 1 章的唯一任务不是介绍家族，而是让读者站到主角这一边。**

四件事，按顺序：

1. **第一句话就是冲突**。最好是别人踩到主角脸上，或主角正被当众否定。禁止天气、背景、起床、走路上学、族史回顾。
2. **处境惨，但主角不蠢不怂**。惨要具体（被扣月俸、被夺灵田、被赶去守祖坟、被当众打断修行），不蠢要看得见（他知道对方要什么、他留了一手）。
3. **金手指亮相，并且立刻见效一次**。家族文里金手指与「族」有关最好（族运、祖灵、族库、族谱、血脉、贡献点），亮相即在眼前困境上兑现。
4. **族谱后置**：本章只需要读者记住三个信息——主角在族里地位最低、家族整体在走下坡或被欺压、有一个明确的倒计时或期限压力。

**第 1 章禁用清单**：族谱大名单、三房七脉介绍、境界体系讲解、家族百年史、超过两句的景物描写、主角内心独白超过 150 字。

**系统文第 1 章特别纪律**：面板首次出现在**冲突进行中**，不是主角睡醒看见。面板总行数 ≤ 6 行，只展示与当前困境直接相关的一两项。

---

## 三、第 2 章：小打脸 + 压力升级

骨架：

```
承接：第1章钩子指向的那个人/那件事找上门
冲突：对方用家族规矩或资源卡他（月俸、灵田、名额、族规）
爽点：主角用金手指解决眼前小事，并打脸一个具体的人（不是群体）
升级：对方背后站着更大的后台（房头、长老之子、邻族）
钩子：主角看见自己真正的短板，或发现家族的秘密一角
```

家族文专用要点：

- 打脸要**在家族内部**完成，让「辈分、规矩、资源分配」成为武器，别急着打外人。
- 打完脸必须**收益落地**：拿到灵石、丹方、灵田、族内名额，读者要看见白纸黑字的好处。
- 升级压力要来自**关系网**，不是凭空冒出强者：打了一个外门弟子，来的应该是他哥、他师傅、他那一房。

---

## 四、第 3 章：大爽点 + 全书级钩子

骨架：

```
承接：第2章的升级压力落到一个公开场合（族比、祠堂议罚、族老大会、开脉大典、族祭）
冲突：主角被逼在众人面前证明自己，或家族被逼当众认输
爽点：当众碾压，层层递进（先是同辈震惊 → 房头改口 → 长老沉默 → 族长出面）
收益：家族地位或资源的可见变化 + 主角个人收益
钩子：家族的一个秘密浮出水面，且与主角身世/血脉/祖上有关
```

**第 3 章的「层层递进」是家族文最大的爽点来源**：要让读者看见不同辈分、不同立场的人依次变脸，一句一个人，不要写成一段总结。

**系统文第 3 章特别纪律**：第一次给一个**有代价的任务或奖励选择**，让读者知道系统不是许愿机。奖励档位控制住：第 3 章的奖励不要超过前两章总和的一点五倍。

---

## 五、第 4–5 章：把爽点变成路径

三章之后读者已经留下，接下来两章要让读者相信「这本书有得看」：

- **第 4 章**：暴露金手指的硬限制（次数、代价、暴露风险），主角在限制下想办法，靠脑子赢一次——这一章专门防止读者觉得「主角无敌没意思」。
- **第 5 章**：给出中长期目标（一个具体的、可数清楚的目标：族比夺魁、拿到族库第三层钥匙、把自家这一房从旁支提成嫡支），并给出第一份修炼资源与家族资源。

**第 4–5 章是「留存章」**，可以没有大爽点，但必须有 1 个小爽点 + 明确的目标线。禁止出现纯过渡章。

---

## 六、家族文开篇常见错误与改法

| 错误 | 读者反应 | 改法 |
|---|---|---|
| 第 1 章先讲族史与七房八脉 | 记不住，划走 | 只留「主角最低、家族被欺」，族谱拆到 5 章内分批给 |
| 主角被家族压榨三五章不还手 | 憋屈，弃书 | 受气不过半章，本章或下一章前三分之一还回去 |
| 长辈集体降智，硬要为难主角 | 假，出戏 | 给长辈一个说得通的动机：资源不够分、嫡庶之争、有人许了好处 |
| 金手指一开就无敌 | 三章后无趣 | 第 1 章就给硬限制，第 4 章专门展示限制 |
| 系统面板一次贴 20 行 | 刷屏，跳过 | 一次 3–5 行，只贴冲突相关的项 |
| 越级获胜没有解释 | 崩，弃书 | 每次越级必须给条件：地利、阵法、丹药、偷袭、对方有伤 |
| 族战写成流水账 | 无感 | 一场族战只写 3 个具体的人 + 1 个决定胜负的变数 |
| 前 3 章出场 15 个人 | 混乱 | 用「三代以内才提名字」纪律控制 |
| 第 1 章交代完整境界体系 | 像设定集 | 只给对比：主角最弱，对方能一掌拍碎演武石 |
| 每章都在铺垫，第 3 章才起势 | 番茄直接死 | 第 1 章末尾必须已有一次金手指兑现 |

## 八、第 1 章前 800 字节拍表（按行数分配）

以番茄 2000 字章为例（手机阅读，一行约 20–24 字，即约 90 行）：

| 段落 | 字数 | 必须发生什么 | 禁止出现 |
|---|---|---|---|
| 开篇第一句 | 10–30 字 | 直接的冲突动作或羞辱台词 | 天气、地名、族史 |
| 冲突展开 | 200–300 字 | 对方施压的具体手段（扣月俸、夺名额、当众罚跪） | 主角内心长篇独白 |
| 主角处境 | 150–250 字 | 用数字交代惨状（月俸几枚、期限几天、弟弟要多少灵石） | 家族整体介绍 |
| 金手指亮相 | 150–250 字 | 触发条件 + 一次立即可见的收益 | 系统说明书式旁白 |
| 第一次兑现 | 250–350 字 | 当场解决眼前的小问题，让一个人闭嘴或变脸 | 一步到位解决全族危机 |
| 压力升级 | 200–300 字 | 对方后台出现或规矩卡死，把危机推大 | 平地冒出强者 |
| 章末钩子 | 80–150 字 | 指向更大的人或更深的秘密 | 收束式总结 |

**总字数偏差控制在 ±10%**。写完直接用 `scripts/writing_check.py` 验段长与钩子。

## 九、可直接复制使用的开篇示例（原创，供模仿句式而非照抄情节）

范本例：苍麓戚氏，主角为三房庶支少年，金手指是能看见族运流向。

**第一句话（必须有冲突）**

```
「三房的月俸，从今天起减半。」
```

**处境用数字说话**

```
三房一共七口人，两个开脉过的长辈，五个没开脉的孩子。
减半之后，一个月剩两枚下品灵石。
弟弟明年开脉，族里开脉要交三十枚。
```

**金手指在冲突中亮相（面板只贴 4 行）**

```
他抬头那一瞬，祖祠的方向亮了一下。

【族运流向】
　三房：-7（外流）
　长房：+7（承接）
　流向源头：祖祠·东三龛
```

**第一次兑现（当场，小而具体）**

```
「这字，写反了。」
他指着族田分账的册子。
「三房的份额划到长房名下，落款盖的是长房的印。按族规，改印要族老会三人签名，这里只有一个。」
祠堂里静了一息。
```

**章末钩子**

```
曾祖的牌位下压着一张纸。
他只看清了两个字：借运。
```

**句式纪律**：
- 台词短，一句不超过 30 字，不写「他愤怒地说道」这类标签。
- 面板独占段落，前后各空一行，不超过 5 行。
- 一处只放一个信息点，不要在一段里塞族规 + 境界 + 人名。
- 三章的示例结构可以参考，**具体情节与设定必须自创**，不得套用任何已有作品桥段。

## 十、可直接填写的前五章细纲模板

```
第X章 章节标题（标题里带具体动作或冲突，不带抒情）
承接：上一章的钩子被谁/什么事接住
冲突：谁对谁做了什么，卡住的是什么（规矩/资源/实力）
爽点：金手指怎么用，谁被打脸，代价是什么
收益：主角拿到什么（具体到数目/物件/名分）
钩子：指向谁/指向什么更大压力
字数：番茄约2000；起点约2500
```

填完五章后，只做一遍检查：**把每章的「收益」连起来读**，如果看不到主角在家族里的位置一节一节往上走，就说明家族成长线没立起来。
