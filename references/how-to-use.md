# jiazu-xiuxian · 家族修仙 / 系统文 AI 写小说技能包

面向**起点（付费订阅）**与**番茄（免费阅读）**的网文写作技能包，主线是**家族修仙文**（族谱、字辈、族产、族战、族运），并覆盖**系统文**基础与两者的融合写法。

安装一次，之后在任何 DSH 会话里说「用家族修仙技能开一本书」即可调用。

---

## 一、它是什么

一个 **DSH skill 目录包**（本地技能），不是独立 App：

- 技能入口：`SKILL.md`（人设、开工流程、硬性写作纪律、输出格式、交付前必做）
- 知识库：`references/` 8 篇，按需加载
- 校验工具：`scripts/` 2 个纯标准库 Python 脚本，交付前跑一遍

调用方式（在会话里）：

```
skill: jiazu-xiuxian
```

或直接说需求，模型会按 `whenToUse` 自动匹配：「用家族修仙的路子开一本番茄的书，主角靠族运面板」。

---

## 二、安装位置

技能按目录发现，两个位置任选其一（**项目根优先于用户根**）：

| 位置 | 路径 | 作用范围 |
|---|---|---|
| 项目根（优先级 100） | `D:\小说\.dsh\skills\jiazu-xiuxian\` | 只在 `D:\小说` 这个工作区可见 |
| 用户根（优先级 400） | `C:\Users\admin\.dsh\skills\jiazu-xiuxian\` | 所有会话可见 |

本包已同时放在这两处，内容一致。

> 注意：技能基础设施必须处于启用状态，否则本地技能不会被发现。需要的插件：
> `@deepseek-ai/dsh-skill`（已启用）、`@deepseek-ai/dsh-skill-filesystem`、`@deepseek-ai/dsh-tool-skill`、`@deepseek-ai/dsh-skill-badge`。
> 用 `plugin_manager` 的 `list_plugins` 查看 `include:skill-filesystem` 等条目是否为 `enabled: true`；未启用时技能目录为空，加载会报 unknown。

## 四、典型用法

### 1. 开一本新书（完整流程）

```
用 jiazu-xiuxian 技能，在番茄开一本家族修仙 + 系统文：
主角是个三代旁支，金手指是能看见族运。
计划 120 万字，日更 6000，单章 2000。
```

模型会依次交付：建族表 → 体系表 → 书名/简介/标签 → 分卷大纲 + 前 10 章细纲 → 黄金三章 → 逐章正文。

### 2. 只写一章

```
按 jiazu-xiuxian 的规矩写第 12 章：族比初赛，主角以炼气三层对炼气六层。
```

### 3. 改稿 / 拆书

```
用家族修仙技能拆一下我这章，只讲最致命的 3 条：<贴正文>
```

### 4. 手工跑体检脚本

```powershell
$py = "C:\Users\admin\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
$root = "D:\小说\.dsh\skills\jiazu-xiuxian"

# 章节体检（可传多个文件或一个目录）
& $py "$root\scripts\writing_check.py" "D:\小说\某书\第12章.txt"

# 族谱体检
& $py "$root\scripts\family_check.py" "D:\小说\某书\族谱.txt"

# 用法说明
& $py "$root\scripts\writing_check.py" --help
& $py "$root\scripts\family_check.py" --help
```

## 五、写作纪律速查（SKILL.md 的浓缩版）

| 纪律 | 标准 |
|---|---|
| 第一句 | 必须是冲突，不写天气/背景/族史 |
| 每章 | ≥1 个小爽点 + 1 个章末钩子，缺一不可 |
| 主角憋屈 | 不超过一章（番茄不超过半章） |
| 家族成长 | 每 3–5 章让读者看见一次可见变化 |
| 辈分称呼 | 新角色出场先定辈分再给名字 |
| 数字 | 灵石/贡献点/物价按体系表写，不随手加零 |
| 越级 | 必须给条件，且不连续两章同一招 |
| 金手指 | 必须有代价（次数/资源/暴露/反噬） |
| 系统面板 | 一次 3–5 行，且出现在冲突中 |
| 正文格式 | 纯文本，不用 Markdown 语法，段不过 3 行，对话用「」 |
| 时效性信息 | 签约/榜单/全勤/红线一律联网核实，区分官方口径与同行经验 |
